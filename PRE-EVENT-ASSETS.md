**Skill - Pilot : A Cognitive Career Navigator**

This project builds on work prepared before the event. The pre-event assets include the **AgentSpec / Cognitive Career Navigator design document**, which defines the problem, user workflow, state machine, data model, agent boundaries, human checkpoints, evidence-verification approach, adversarial test cases, and planned MVP architecture. The design also includes the proposed use of persistent **SQLite** state, **Playwright** for job-description retrieval, **Streamlit** for the application UI, typed records/schemas, and model calls for teaching, assessment, misconception classification, requirement extraction, and recommendation explanation. No pre-event dataset gathered specifically for this project is being claimed, and no previously completed implementation code is being claimed unless separately added to this declaration. Any application code, integrations, evaluation results, datasets collected during the event, and event-specific prompts/evaluation cases will be created during the event. Pre-existing/open-source libraries and tools planned for use include **Streamlit, SQLite, Pydantic, Playwright, and the selected LLM/API client**; these are implementation dependencies rather than pre-built project functionality.
