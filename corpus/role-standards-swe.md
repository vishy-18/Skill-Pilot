# Industry Role Standards & Skill Benchmarks — Software Engineering Intern

## 1. Skill Rubrics & Benchmark Levels

For a student targeting a **Software Engineering Intern** role, skills are classified into three required proficiency tiers:

### Tier 1: Core Foundation (Required Level: High)
- **Python**: Ability to write idiomatic Python, structure modules, handle exceptions gracefully, and implement type annotations. Minimum target score: 75+.
- **REST APIs**: Clear differentiation of HTTP verbs, idempotency, status code semantics (2xx, 4xx, 5xx), and JSON payload serialization. Minimum target score: 70+.
- **Data Structures & Algorithms (DSA)**: Mastery of arrays, hash maps, recursion, searching, sorting, and algorithmic trade-offs. Minimum target score: 70+.

### Tier 2: Supporting Skills (Required Level: Medium)
- **SQL**: Writing aggregate queries, multi-table JOINs, foreign key constraints, and understanding ACID transactions. Minimum target score: 60+.
- **Git**: Branching, commits, rebasing, pull requests, and resolving merge conflicts cleanly. Minimum target score: 60+.

### Tier 3: Bonus / Preferred Skills (Required Level: Low / Developing)
- **Docker & Linux**: Basic containerization, environment configuration, and CLI commands. Target score: 40+.

## 2. Common Student Deficiencies & Risk Areas
- Confusing HTTP methods (specifically treating POST as a retrieval method or GET as a state-mutating method).
- Over-reliance on self-reported skill proficiency without project or assessment evidence.
- Gaps between academic syllabus knowledge and industry API building standards.
