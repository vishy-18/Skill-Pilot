# TechCorp & CloudScale Software Engineering Job Descriptions (2024)

## Role: Software Engineering Intern — Backend Focus

**Company:** TechCorp India  
**Location:** Bengaluru, India / Remote  
**Type:** Internship (6 months)

### About the Role
TechCorp is seeking motivated Software Engineering Interns to join our backend infrastructure and product teams. You will work on microservices, API integrations, and scalable data processing pipelines serving millions of active users.

### Required Qualifications
- **Python**: Demonstrated proficiency in Python 3.10+ programming, including object-oriented design, async concepts, and clean coding standards.
- **SQL & Relational Databases**: Solid understanding of SQL querying, relational database design, joins, indexes, and transactions with SQLite or PostgreSQL.
- **REST APIs**: Practical knowledge of REST API architecture, HTTP methods (GET, POST, PUT, DELETE), status codes, request/response headers, and API payload modeling.
- **Data Structures and Algorithms (DSA)**: Strong grasp of core data structures (arrays, hash tables, linked lists, trees, graphs) and algorithmic complexity (Big-O notation).
- **Version Control**: Working knowledge of Git for collaborative development, branch management, pull requests, and merge conflict resolution.

### Preferred Qualifications
- **Docker**: Exposure to containerization, Dockerfiles, and multi-stage container builds.
- **Automated Testing**: Experience writing unit tests with pytest or unittest.
- **CI/CD**: Familiarity with GitHub Actions or automated deployment pipelines.

## Role: Junior Backend Developer

**Company:** CloudScale Systems  
**Location:** Hyderabad, India  
**Type:** Full-time

### Key Requirements
- Design and maintain production-ready RESTful APIs in Python using FastAPI or Flask.
- Implement efficient database queries in PostgreSQL/SQLite and manage migration scripts.
- Integrate third-party webhooks, event queues, and caching layers with Redis.
- Participate in code reviews, architectural discussions, and automated end-to-end testing.
- Must demonstrate hands-on projects showing REST API design and relational database persistence.
